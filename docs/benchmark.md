# Benchmark (Metal / MPS)

Hardware: Apple M5 Pro, 64 GB unified memory, macOS 26.6.2. Python 3.13.18, torch 2.15.0, reference idol-sdk
8db7003. Date 2026-11-24. One session: `tools/bench_all.sh` (14:13-14:52), plus avocado at 1,048,576 run after a
pause (same machine, same day, the four variants back to back). Each row is one process.
- Each process loads the pipeline, runs a 2-step, 32,768-Gaussian warm-up (shader/graph compilation; Inductor
  compile for torch.compile), then one timed request.
- Stage timers synchronise the device around each stage. Peak memory is sampled every 10 ms: process
  phys_footprint, and MPS driver allocation.
- Order is flipped between rounds and images.

Variants:
- **ref**: the official pipeline as shipped. Eager on MPS: upstream `optimize=True` is CUDA-only.
- **compile**: the official optimize path forced on MPS, i.e. `compile_for_sampling` (torch.compile of the blocks
  and RePo layers, real-valued RoPE) plus batched CFG.
- **parity**: the fast build without the collapsed unconditional context.
- **fast**: this port, the headline.

parity and fast load their kernels from the local kernel-builder build (`kernel/build`).

Columns:
- "total" covers preprocess (BiRefNet), both encoders, sampling, both decoders and Gaussian activation. It
  excludes model load, warm-up and the PLY write (~0.02 s, the same for all variants).
- "other" = total - sample - decode.
- "PLY == reference": sha256 of the written PLY equals that of the reference dump run (`runs/ref_*_A`, an earlier
  session). The reference is deterministic on this device: its two independent runs per config had equal sha256.

Closeness is measured against the reference dump of the same config (`tools/closeness.py`).
- latent: final sampled latent [1, 8192, 16].
- anchor-cell overlap: fraction of octree anchors whose level-8 cell matches as a multiset. Systematic resampling
  is discontinuous in the latent, so any latent change re-draws most anchors.
- Chamfer: mean nearest-neighbour distance between the Gaussian centres, both ways, with the object inside
  [-0.5, 0.5]^3.
- The reference's own spread is the compile variant's row.

Rendered-view PSNR was not measured: no 3DGS rasterizer is available on MPS without a separate port.
